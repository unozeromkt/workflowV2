# 1. Objetivo del proyecto

Construir un sitio web corporativo para **WORKFLOW INT.** utilizando exclusivamente los textos del documento fuente.

El sitio debe:
- Presentar a WORKFLOW INT. como compañía de estrategia, tecnología y operación inteligente.
- Explicar el problema que resuelve.
- Comunicar su visión “Human in the Loop”.
- Organizar claramente sus cinco líneas de servicio.
- Mostrar industrias en las que tiene experiencia.
- Mostrar metodología, experiencia certificada y presencia internacional.
- Facilitar contacto comercial mediante CTA hacia WhatsApp.
- Mantener una estética tecnológica, oscura, premium y corporativa inspirada directamente en el documento.
